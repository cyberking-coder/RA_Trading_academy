# RA Trading Academy — Website

A premium, animated single-page marketing website for **RA Trading Academy** (रा ट्रेडिंग एकेडमी), Kolhapur's 5.0★-rated Forex & stock-market trading institute.

## ✨ Features
- Awwwards-style dark aesthetic with a live gold/green/violet gradient system
- Animated preloader with progress counter
- Custom blend-mode cursor
- Hero with an interactive **canvas particle network + animated market trend line**
- GSAP-powered text reveals, count-up stats, scroll parallax & progress bar
- Infinite marquee, auto-scrolling review wall (real Google reviews)
- 3D tilt cards, magnetic buttons, smooth section reveals
- Fully responsive + `prefers-reduced-motion` support

## 🧱 Stack
Pure HTML/CSS/JS. Only external dependency is **GSAP** (via CDN) for animation.
No build step — just open `index.html`.

## 🚀 Run locally
```bash
python3 -m http.server 8000
# visit http://localhost:8000
```
